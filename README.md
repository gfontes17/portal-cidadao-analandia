# Portal Cidadão Analândia — protótipo v0.3

Versão estática e simplificada, com prioridade para dinheiro público e gastos municipais.

## Como testar
Abra `index.html` no navegador. Não é necessário instalar nada.

## Conteúdo desta versão
- Página inicial simplificada com quatro acessos principais.
- Guia “Dinheiro público” com links oficiais e explicações introdutórias.
- Sem números financeiros próprios ainda: os valores só devem ser publicados após conferência da fonte, do período e do significado.
- Paleta em vermelho, branco e tons claros.
- Layout responsivo para celular e computador.

## Links oficiais incluídos
- Prefeitura de Analândia: https://www.analandia.sp.gov.br/
- Licitações da Prefeitura: https://analandia.sp.gov.br/licitacao
- Transparência da Câmara: https://camaraanalandia.sp.gov.br/transparencia/
- Portal da Câmara: https://camaraanalandia.sp.gov.br/portal/

O endereço direto do Portal da Transparência da Prefeitura ainda precisa ser confirmado pela navegação do site institucional.

## Publicação gratuita
É possível publicar o protótipo estático usando GitHub Pages ou Cloudflare Pages. O projeto não utiliza banco de dados nem coleta dados pessoais nesta etapa.
